# Structural Crime Scene Processing

Structural Crime Scene Processing is a publicly shared, self-contained project for rethinking how crime scenes are handled, processed, interpreted, reviewed, and taught.

Its core claim is simple:

- legacy crime-scene systems are often narrative-led, collection-heavy, and explanation-dependent
- Structural Crime Scene Processing is falsifier-led, boundary-aware, transition-aware, and built to reduce hypothesis space without contaminating it

This repository is being prepared for public sharing because the work is meant to be read, studied, taught from, cited, and used responsibly in legitimate educational and operational settings. It is not an open-source repository.
