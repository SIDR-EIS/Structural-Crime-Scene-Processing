# Structural Crime Scene Processing

## Mixed Investigator-Prosecutor Calibration Packets

## Draft 1

---

## Purpose

This document provides structured calibration packets for mixed investigator-prosecutor training and review sessions.

Its purpose is not to run another ordinary exercise.

Its purpose is to expose and resolve cross-role disagreement about what the package actually supports.

These packets are built for the moment when investigators, prosecutors, supervisors, or legal reviewers are all using the same documents but still operating with different truth standards.

That gap is common.

It is also one of the main ways reform quietly fails.

Investigators may think they are being honest.

Prosecutors may think they are being practical.

Supervisors may think they are being efficient.

If those roles are still grading the same package by different standards, the system will drift back toward narrative performance no matter how many documents it owns.

These packets are designed to prevent that.

---

## What Calibration Is For

Calibration is not the same as scoring.

Scoring asks:

- how did this learner perform
- what should they score
- are they ready, not ready, or in need of remediation

Calibration asks something different:

- did two or more roles read the same package through the same structural logic
- where did their standards diverge
- what disagreement came from role pressure rather than from the package
- what phrasing, threshold, or support rule needs to be unified before live use

If an investigator says "the package supports this theory" and a prosecutor says "I need it cleaner" and both think they are being disciplined, calibration has not happened yet.

This document is for that problem.

---

## When to Use These Packets

Use these packets:

- before mixed investigator-prosecutor pilot work begins
- before legal-review scenarios are used for certification
- after repeated conflict between detective and prosecutor readouts
- when supervisors detect drift between package truth and legal wording
- when new prosecutors or new investigative leads join the system
- after a transfer failure, reentry dispute, or demonstrative overclaim event

Do not wait until trial pressure is high to discover that the roles disagree about what counts as lawful support.

By then the disagreement usually gets solved by hierarchy, speed, or rhetoric instead of by structure.

---

## Participants

Recommended participants per session:

- one detective or investigative lead
- one prosecutor or downstream legal reviewer
- one supervisor or review-board representative
- one facilitator or instructor

Optional participants:

- scene technician when the packet turns on threshold, anchor, or packaging interpretation
- laboratory representative when lab discrimination or null-result reading is central
- case coordinator when transferability and residue ownership are central

Keep the group small enough that disagreement can be seen clearly.

Large mixed sessions often turn calibration into performance.

---

## Calibration Rules

### Rule 1: Independent first read

Each participant must write an initial position before discussion begins.

If roles talk too early, seniority and fluency will hide real disagreement.

### Rule 2: Package first, role second

Participants should answer from the package before answering from their role pressures.

The question is not "what would I want if I were charging this."

The question is "what does the package support if read lawfully."

### Rule 3: Disagreement must be made visible

Do not smooth disagreement through vague phrases like:

- partly
- mostly
- probably enough
- I see both sides

The packet only works if the actual fault line is written down.

### Rule 4: Rewrite, do not only argue

Once disagreement is identified, the group must produce a shared rewrite, threshold statement, or decision note.

If a group can talk well but cannot produce a joint bounded output, calibration has not finished.

### Rule 5: Preserve residue

If convergence occurs only because unresolveds were deleted, the packet failed.

---

## Standard Packet Workflow

Every calibration packet should be run in seven stages.

### Stage 1: Silent independent read

Each participant reads the packet alone and records:

- contemplated move
- strongest anchors
- what those anchors do not prove
- central residue
- whether the move is supported fully, partially, or not yet

### Stage 2: Role-position capture

Each participant writes a short role-specific statement:

- detective position
- prosecutor position
- supervisor position if present

This shows where role pressure begins to alter package reading.

### Stage 3: Difference ledger

The facilitator writes all differences into one list:

- support threshold differences
- wording differences
- residue tolerance differences
- transferability concerns
- urgency pressures

### Stage 4: Forced anchor review

The group must then answer only anchor questions:

- what are the strongest anchors
- what do they constrain
- what do they not constrain
- what has actually been eliminated

No one is allowed to solve disagreement by appealing to experience, confidence, or practical need at this stage.

### Stage 5: Joint bounded output

The group must jointly produce one of the following:

- bounded charging paragraph
- bounded affidavit paragraph
- transfer-risk note
- reentry activation note
- demonstrative review note

### Stage 6: Residue and redesign statement

The group must write:

- what remains unresolved
- what structure is still needed
- what redesign signal should travel upstream or downstream

### Stage 7: Convergence assessment

The facilitator records:

- whether convergence happened
- whether it was lawful
- what language rules were agreed
- what role tendency caused the main distortion

---

## Standard Packet Outputs

Every packet should produce the following:

- independent role-position sheets
- a difference ledger
- a joint anchor summary
- a bounded shared rewrite or note
- a residue / redesign statement
- a convergence result

If a session ends without these written outputs, the group probably confused discussion with calibration.

## Packet A. Charging Alignment on the Apartment Hallway Case

### Objective

Align investigators and prosecutors on the difference between a package that supports serious charging review and a package that supports a smooth motive-rich closed sequence.

### Core disagreement to surface

Investigators often feel that the suspect's building presence, the victim's outgoing call, and the threshold disturbance make the charge theory sufficiently obvious.

Prosecutors under pressure may agree with that instinct while still asking for cleaner language.

The calibration goal is to force both sides to admit exactly what remains unearned.

### Recommended participants

- detective or case investigator
- charging prosecutor
- supervisor or review-board representative
- facilitator

### Source materials

- `Exercise 1. Charging Review in the Apartment Hallway Case`
- the corresponding legal answer key
- the legal exemplar charging note and rewrite

### Packet prompt

The group must decide whether the current package supports:

- full charging language
- bounded charging language
- continued charging review only

The group must also jointly rewrite the overclaimed detective summary.

### Independent-read questions

Each participant answers:

1. Is the move fully supported, partially supported, or not yet?
2. Which three phrases in the current summary are least defensible?
3. What is the strongest anchor?
4. What does that anchor fail to prove?
5. What residue must remain visible in any charging note?

### Difference-ledger prompts

The facilitator should ask:

- Does the detective think the threshold problem is mostly solved?
- Does the prosecutor think motive language is harmless because the actor set is narrow?
- Does the supervisor reward movement toward filing more than movement toward lawful wording?

### Forced anchor review

The group must not proceed until it can jointly state:

- the strongest three anchors
- what each one constrains
- what each one does not constrain
- why domestic framing is presently category pressure rather than settled support

### Required joint output

Produce:

- one bounded charging paragraph
- one list of live residues
- one follow-up request to investigators that asks for structure instead of a cleaner story

### Convergence standard

Convergence is achieved only if the group can agree that:

- serious legal action may be supportable
- the prior summary overclaimed the package
- motive, initiation site, and exact threshold path remain more bounded than the old wording suggests

If the group converges only by deleting residue, the facilitator should mark the packet failed.

### Facilitator watchpoints

Watch for:

- detective frustration disguised as "common sense"
- prosecutor comfort with domestic language because it sounds ordinary
- supervisor impatience with structural caveats

### Signs of successful calibration

- the rewritten paragraph is narrower but still operational
- both detective and prosecutor can say what the strongest anchors do not prove
- follow-up requests ask for hierarchy, elimination, or threshold clarification rather than for stronger narrative

## Packet B. Warrant Threshold Alignment on the Quiet Office Case

### Objective

Align investigators and prosecutors on the difference between an unexplained path problem and a fully actor-attributed hidden-entry sequence.

### Core disagreement to surface

Investigators and prosecutors under urgency often slide from:

- "something happened before the victim entered"

to:

- "this employee entered early, concealed the act, and killed the victim."

The packet must expose that slide directly.

### Recommended participants

- detective
- reviewing prosecutor
- technical analyst or lab representative if available
- facilitator

### Source materials

- `Exercise 2. Warrant Review in the Quiet Office Case`
- the corresponding legal answer key
- the legal exemplar warrant memo and affidavit rewrite

### Packet prompt

The group must decide whether the package supports:

- the contemplated target-specific warrant as described
- a narrower warrant or process request
- no present legal move against the named target

### Independent-read questions

Each participant answers:

1. Which exact affidavit clauses exceed the package?
2. Does the package support the present move fully, partially, or not yet?
3. What is the difference between a path anomaly and actor attribution in this file?
4. What narrower move, if any, remains lawful?

### Difference-ledger prompts

The facilitator should ask:

- Is the detective relying on plausibility rather than linkage?
- Is the prosecutor treating urgency as if it creates attribution?
- Is anyone using HVAC language as intent proof without closing dependency links?

### Forced anchor review

The group must jointly separate:

- observed state
- bounded sequence
- conditionals
- rhetoric

Then it must identify:

- which anchors support a path problem
- which anchors support named-employee attribution
- what gap still exists between the two

### Required joint output

Produce:

- one bounded affidavit paragraph
- one target-clarification note
- one short statement explaining whether the legal move is fully, partially, or not yet supported

### Convergence standard

Convergence is achieved only if the group can jointly explain why a path problem is not automatically actor proof.

If the final paragraph still uses hidden-entry murder language as settled fact, the packet failed.

### Facilitator watchpoints

Watch for:

- "everyone knows what this means" thinking
- overreliance on professional drafting confidence
- efforts to preserve the warrant by inflating the memo instead of narrowing the move

### Signs of successful calibration

- the rewrite remains useful without naming an unearned sequence
- actor-attribution gaps are explicitly acknowledged
- the group requests better structure rather than stronger theory

## Packet C. Transfer Fragility Alignment on the Warehouse Case

### Objective

Align prosecutors, investigators, and supervisors on how to recognize a file that looks mature but is still dependent on hidden explanatory labor.

### Core disagreement to surface

Investigators may believe the file is mature because it is technically dense.

Prosecutors may believe the file is mature because previous reviewers sounded confident.

Supervisors may believe the file is mature because no one has recently escalated it.

The packet is designed to break that false stability.

### Recommended participants

- incoming prosecutor
- senior detective or case owner
- supervisor or review-board representative
- technical specialist or analyst if available
- facilitator

### Source materials

- `Exercise 3. Trial Transfer in the Warehouse Loading Bay Case`
- the corresponding legal answer key
- the legal exemplar handoff-risk memo and timeline rewrite

### Packet prompt

The group must decide whether the inherited file is:

- transfer-stable
- usable with limited stabilization
- materially transfer-fragile and in need of structure recovery before trial posture hardens

### Independent-read questions

Each participant answers:

1. What sentence in the inherited timeline is least defensible?
2. What signs suggest oral rescue is carrying the file?
3. What must be externalized before the file is safe to transfer?
4. Is technical density helping or hiding the main problem?

### Difference-ledger prompts

The facilitator should ask:

- Does the investigator assume the prior prosecutor's confidence equals sufficiency?
- Does the prosecutor assume oral explanation is acceptable because the case is specialized?
- Does supervision equate lack of recent friction with transfer health?

### Forced anchor review

The group must identify:

- what the package strongly supports
- what remains partial
- which major claims still depend on one analyst or one oral explanation chain

### Required joint output

Produce:

- one transfer-risk memo
- one narrowed timeline paragraph
- one list of package elements that must be externalized before trial posture hardens

### Convergence standard

Convergence is achieved only if the group agrees that transferability is a structural property, not a function of how persuasive the prior team sounded.

If the group resolves concern by saying the analyst can always be called later, the packet failed.

### Facilitator watchpoints

Watch for:

- prestige bias toward experienced prior reviewers
- tolerance for tacit knowledge because the subject matter is technical
- supervisor preference for preserving momentum over exposing hidden reconciliation

### Signs of successful calibration

- the new memo treats transfer fragility as real case risk
- hidden-expert dependence is named explicitly
- timeline language is narrowed without collapsing the seriousness of the case

## Packet D. Reentry Threshold Alignment on the Quiet Office Case

### Objective

Align prosecutors, investigators, and supervisors on what should trigger reentry when a case theory has already hardened socially.

### Core disagreement to surface

Investigators and prosecutors often disagree about when new material is:

- a nuisance
- a challenge to one dependency link
- a reason for formal reentry

Supervisors often worsen this by asking whether the case is "still basically intact" rather than whether the support structure changed.

### Recommended participants

- lead prosecutor
- detective or technical reviewer
- case coordinator
- supervisor
- facilitator

### Source materials

- `Exercise 4. Pretrial Challenge and Reentry in the Quiet Office Case`
- the corresponding legal answer key
- the legal exemplar reentry activation note and narrowed theory note

### Packet prompt

The group must decide whether the new defense-obtained material triggers:

- no formal reentry
- limited clarification only
- formal reentry with narrowed outward-facing theory

### Independent-read questions

Each participant answers:

1. Does the new material change the current theory structurally or only rhetorically?
2. Which dependency links are weakened?
3. What remains strong?
4. What language must now be paused or revised?

### Difference-ledger prompts

The facilitator should ask:

- Is the prosecutor resisting reentry because of sunk posture?
- Is the investigator underreading the new material because the case still feels viable overall?
- Is the supervisor using the wrong threshold, such as "does this completely break the case?"

### Forced anchor review

The group must jointly separate:

- what the new material weakens
- what it leaves intact
- what it newly opens

It must also confirm whether an existing reentry trigger was already documented.

### Required joint output

Produce:

- one formal reentry or non-reentry note
- one narrowed theory statement for outward-facing use
- one follow-up request list

### Convergence standard

Convergence is achieved only if the group agrees on the threshold question:

not "does this destroy the case"

but "does this materially alter support for a dependency link in the current theory."

### Facilitator watchpoints

Watch for:

- prior theory repetition creating emotional lock-in
- irritation with reentry being disguised as rigor
- team members trying to preserve prior demonstratives because they already invested work in them

### Signs of successful calibration

- reentry is treated as structural duty, not embarrassment
- outward-facing theory is narrowed where needed
- the group can say exactly what changed and what did not

## Packet E. Demonstrative Discipline Alignment on the Apartment Hallway Case

### Objective

Align investigators, prosecutors, and supervisors on the rule that visuals are not exempt from package truth.

### Core disagreement to surface

Trial teams often say:

- it is only a visual aid
- the jury needs a clear picture
- everyone knows the exact-path graphic is simplified

Investigators may feel uneasy about that but not know how to object structurally.

This packet gives them that structure.

### Recommended participants

- trial prosecutor
- detective
- supervisor or review-board representative
- facilitator

### Source materials

- `Exercise 5. Demonstrative Audit Before Trial`
- the corresponding legal answer key
- the legal exemplar demonstrative review note and visual-standards note

### Packet prompt

The group must decide whether the current demonstrative:

- is structurally usable
- is usable only after narrowing
- should be rebuilt from the ground up

### Independent-read questions

Each participant answers:

1. Which visual element is most dangerous?
2. What does the package actually support visually?
3. Which part of the graphic is cleaner than the package?
4. What should a lawful replacement look like?

### Difference-ledger prompts

The facilitator should ask:

- Is the prosecutor treating visual persuasion as outside support rules?
- Is the detective deferring because the graphic "belongs" to trial strategy?
- Is the supervisor confusing persuasive usefulness with structural lawfulness?

### Forced anchor review

The group must jointly identify:

- what exact-path support exists
- what exact timing support exists
- what motive or staging support exists
- what remains zone-level or interval-level rather than exact

### Required joint output

Produce:

- one demonstrative review note
- one revised slide-language block
- one short visual-governance standard

### Convergence standard

Convergence is achieved only if the group agrees that visual clarity cannot outrun package truth.

If the group leaves the exact arrow path, motive banner, or staging label in place without stronger support, the packet failed.

### Facilitator watchpoints

Watch for:

- advocacy exceptionalism
- dismissal of detective discomfort as mere caution
- claims that the audience will "understand the simplification"

### Signs of successful calibration

- the revised visual language stays useful but bounded
- the team accepts that graphics can overclaim faster than paragraphs
- investigators and prosecutors use one standard for both prose and visuals

## Facilitator Failure Modes

### Letting seniority collapse disagreement

If the most experienced person speaks first and everyone else adjusts, calibration has been replaced by hierarchy.

### Solving the session with compromise language

Middle-ground phrasing is not success if it hides the real fault line.

### Treating role pressures as excuses

Urgency, filing pressure, and courtroom pressure explain why disagreement happens. They do not excuse ignoring it.

### Failing to force a joint output

If the group leaves without a shared rewrite or note, the session was a discussion, not a calibration packet.

### Allowing rhetoric to outrun the package again inside the calibration room

Calibration sessions can reproduce the same problem they are meant to fix if the facilitator rewards polished explanation more than bounded writing.

## Recommended Use Sequence

Run these packets in this order:

1. Packet A. Charging Alignment
2. Packet B. Warrant Threshold Alignment
3. Packet D. Reentry Threshold Alignment
4. Packet C. Transfer Fragility Alignment
5. Packet E. Demonstrative Discipline Alignment

This order works because it moves from:

- charging sufficiency
- to threshold documents
- to theory narrowing
- to transferability
- to courtroom presentation

That sequence forces the mixed team to converge before the most rhetorically dangerous stage.

---

## Closing Note

The main value of calibration is not agreement for its own sake.

The main value is that it stops roles from silently teaching one another the wrong lesson.

If investigators learn that prosecutors will reward clean unsupported sequence, they will produce it.

If prosecutors learn that investigators expect oral rescue and prestige deference, they will tolerate it.

If supervisors learn that mixed-role disagreement can be covered with momentum, they will keep doing it.

These packets exist to make that hidden curriculum visible and then break it.
